# Sprint 1 — Serious Business Upgrade

## Goal
Turn `dpdpact.info` from a basic starter site into a more credible, modern, conversion-aware DPDP resource hub.

## Sprint Outcomes
- More modern homepage
- Better shared visual system
- More substantial page inventory
- Stronger CTA and trust structure
- Content architecture that supports SEO and lead generation

## Workstreams

### PM / Strategy
- Clarify priorities and what ships now vs later
- Keep scope limited to static-site improvements that materially improve credibility

### UI / UX
- Sharper typography hierarchy
- Cleaner cards/sections/navigation
- Better CTA structure
- More polished footer and page consistency

### Content Engineering
- Expand guide coverage
- Improve metadata and internal linking
- Ensure pages map to search intent and conversion goals

### Frontend Build
- Implement improved homepage
- Add more guide pages
- Improve shared CSS and page structure

## Sprint Deliverables
- Homepage redesign v2.5
- Shared visual polish across pages
- New guide pages:
  - Consent requirements under DPDP
  - Data principal rights explained
  - DPDP penalties explained
  - DPDP for startups
  - Children’s data rules
- Content plan and operating structure docs

## Definition of Done
- Pages exist, are linked, and deploy cleanly
- Homepage feels more credible and modern
- Site has a clear next-step path for users
- Internal linking supports further expansion
