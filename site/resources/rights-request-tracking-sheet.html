Rights Request Tracking Sheet

Use this sheet to log request type, intake channel, verification status, assigned owner, actions taken, and closure notes.

Suggested columns

  • Request date
  • Request type
  • Intake channel
  • Verification status
  • Assigned owner
  • Systems affected
  • Action status
  • Closure date

Use with access/correction, deletion, and grievance-handling guides.
